# RTOS Developments — Silicon Labs

A hands-on repository documenting my daily **RTOS learning, development, and experimentation using Silicon Labs microcontrollers and development boards**.

This repository contains firmware experiments, RTOS concepts, debugging work, peripheral integration, and progressively more advanced embedded applications developed using the Silicon Labs ecosystem.

### Focus Areas

* FreeRTOS fundamentals
* Task creation and scheduling
* Task priorities and preemption
* Queues and inter-task communication
* Semaphores and mutexes
* Event groups and task notifications
* Software timers
* Interrupt and ISR handling
* Task synchronization
* Memory management
* Race conditions and deadlocks
* RTOS scheduling and timing
* GPIO, UART, SPI, I2C and other peripherals
* Low-power and real-time embedded development
* Debugging and performance analysis

### Development Stack

* **Silicon Labs EFR32 / Wireless MCUs**
* **Simplicity Studio**
* **Silicon Labs Gecko SDK (GSDK)**
* **FreeRTOS**
* **C / Embedded C**
* **Silicon Labs debugging and development tools**

### Learning Approach

Each development follows:

**Concept → Implementation → Experiment → Debug → Measure → Document**

The goal is to develop a strong understanding of **RTOS-based firmware development on real Silicon Labs hardware**, progressing from basic task management to production-oriented embedded systems.

> Building every day. Experimenting with RTOS. Learning embedded systems from the firmware level.
